# 観客席（Kankyakuseki）

視聴者がコメントせずにボタンで相づちを打てる、Twitch配信用のマスコット表示です。

## 構成

- `server.js` … 中継サーバー。視聴者のボタン → OBSのオーバーレイへ反応を届ける（Node 18以上、追加インストール不要）
- `public/overlay.html` … OBSのブラウザソースに置く観客席
- `public/viewer.html` … 視聴者側のボタン（のちにTwitch拡張機能になるページ）
- `public/settings.html` … 配信者用の設定画面（独自の言葉、季節の帽子）
- `public/mascot.js` `mascot.css` … マスコットの絵と動き（両方の画面で共用）
- `public/config.js` … 公開時に中継サーバーのURLを書く場所

## 手元で試す

1. `start.bat` をダブルクリック（または `node server.js`）
2. ブラウザで http://localhost:8080/viewer.html を開く（タブ1枚が視聴者1人）
3. OBSのブラウザソースのURLを `http://localhost:8080/overlay.html?room=dev` にする
4. http://localhost:8080/settings.html で独自の言葉と帽子を設定する

## オーバーレイのURLに付けられる設定

| 設定 | 意味 |
|---|---|
| `room=dev` | ボタンからの反応を受け取る部屋（本番ではTwitchのチャンネルID） |
| `channel=名前` | チャットの文面（草、888、!nod など）にも反応させる |
| `names=1` | チャット参加者の名前を表示する |
| `align=left` | 左に寄せる。`right` で右寄せ（既定は中央） |
| `size=160` | マスコットの横幅(px)。大きくしたいときは 220 など |
| `lang=en` | 吹き出しを英語にする（既定はブラウザの言語） |
| `bubble=0` | 吹き出しを消す |
| `max=12` `stay=15` | 最大人数、チャット参加者が退席するまでの分数 |

`room` も `channel` も付けないとデモ表示になります。

## チャンネル独自の言葉と季節の帽子

設定画面で、言葉（最大4つ・8文字まで）と動き（ジャンプ、くるっと回る、手を振る、拍手、笑う、うなずく）を登録できます。
視聴者のボタンに追加され、チャットにその言葉が書かれたときも反応します。設定は `data/rooms.json` に保存されます。

帽子は「自動」だと日付で切り替わります: ハロウィン 10/1〜10/31、クリスマス 12/1〜12/25、桜 3/20〜4/10、麦わら帽子 7/20〜8/31。

## 本番（Twitch拡張機能）にするとき

- Twitchにアップロードするzipには、`public` の中の `overlay.html` 以外の9ファイルを、フォルダーなしで入れます。`config.js` がTwitch上かどうかを見分けて、サーバーのURLを切り替えます
- 環境変数 `SUPABASE_URL` と `SUPABASE_KEY`（シークレットキー）を入れると、設定をSupabaseに保存します。表は `supabase.sql` で作ります。入れない場合は `data/rooms.json` に保存します
- `GET /api/status` で、動作モード・接続数・直近のエラーを確認できます
- 設定を保存できるのは配信者本人だけです（テストモードでは誰でも保存できます）

- 環境変数 `EXT_SECRET` にTwitch拡張機能のシークレットを入れてサーバーを起動すると、Twitchが発行した視聴者トークンだけを受け付けます
- 視聴者のTwitch IDは画面側に渡さず、ハッシュした短いIDだけを使います
